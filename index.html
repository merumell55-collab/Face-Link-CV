Face Link GitHub Edition

GitHub Pagesでそのまま動かせる静的Webアプリです。顔AIは使わず、OpenCV.jsのOptical Flowで自分の顔のポイントを追跡し、 アップロードした人物写真へ表情を反映します。
新機能: 写真/カメラ両方でズーム操作、ドラッグで移動、長押し中の虫眼鏡表示、離した位置にポイント配置、診断表示、保存、基準表情リセット対応。
